## A. Market Focus / Density Strategy
Don't try to cover all of Himachal at once. Build density first.
**Initial cluster — Parvati Valley:** Bhuntar, Jari, Kasol, Manikaran,
Barshaini, Kalga/Kalgha, Pulga, Tosh, Malana, Kheerganga.
**Future clusters (only when demand+supply data justifies expansion):**
Manali/Kullu, Tirthan/Jibhi, Dharamshala/Kangra/Bir, Shimla/Solan belt, Spiti.

Coverage target per location before calling it "ready": at minimum both
**stay + taxi** verified and bookable (extend this bar as data allows —
don't ship a location that implies bookability with zero real fulfillment).

## B. SEO Content Clusters (for keyword/content mapping)
Parvati Valley: Kasol, Kalga, Pulga, Tosh, Barshaini, Malana, Kheerganga,
Sar Pass, Bunbuni Pass and nearby trails.
Other clusters: Manali/Kullu, Mandi, Prashar Lake, Shikari Devi,
Dharamshala, McLeodganj, Triund, Bir-Billing, Shimla, Solan, Mashobra.

Search intent model to design pages around:
- Informational — "How to reach Pulga?"
- Decision — "Kalga vs Pulga"
- Commercial — "Kalga homestay"
- Transactional — "Book Kalga homestay"
Journey: DISCOVER → UNDERSTAND → TRUST → CHOOSE → BOOK.

## C. Technical SEO checklist
- Canonical tags + explicit cross-linking rules between main site content
  pages and portal service pages (avoid duplicate-content cannibalization).
- Structured data (schema.org) for destinations, stays, reviews where real.
- Localization: current URLs use `/en` — confirm whether other locales are
  planned/live before building locale-dependent logic.
- Performance budget: LCP < 2.5s / CLS < 0.1 / INP < 200ms on public pages.
- Accessibility: WCAG AA baseline on public-facing pages — include in flow
  testing, not just a one-off audit.

## D. Demand Intelligence (admin should answer)

results? Which locations have high demand but low supply?
Example format: `Kheerganga — 143 searches — 0 verified guides — HIGH GAP`
`Kalga — 96 searches — 2 stays — RECRUIT MORE STAYS`

## F. Analytics — track without excess PII
landing, search, destination, service, planner, trip, booking, vendor

## G. UX Review Questions (for every important screen)
What does the user want? What do they know / not know? What are they
afraid of? What do they need to trust? What's the next best action?
What information can be removed or deferred? Where could they leave?

## H. 90-Day Direction (relative to program start date — fill in actual
   start date so this doesn't go stale across sessions: START DATE = ____ )
**Weeks 1–4:** Technical SEO baseline, Search Console baseline, keyword/query
mapping, destination architecture, content gap mapping, supply-demand
